This project depicts the classification between the covid 10 and pneumonia using the chest x-ray with the use of mobilenetv2 model which acquired 96% accuracy rate on classification.
The Project contains the following processes to achieve the accuracy:
Data preparation
Image pre-processing
Normalizing the images
Class Distribution
Spliting training and testing dataset
Convert categorical label to numerical label
Model building with mobilenetv2 model
Performance metrics
Predicting Viral infection on unseen chest xray
